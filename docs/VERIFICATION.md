# Проверки и готовность к сдаче

## Выполнено при подготовке кода

- PEP8 backend: пройдено после устранения пробелов/отступов и лишнего импорта.
- Backend: 5 поведенческих тестов пройдены локально с SQLite in-memory. Это не проверка подключения к PostgreSQL.
- Frontend: 1 существующий тест входной страницы пройден.
- Проверки файлов Практикума: 7 из 7 пройдены.
- Terraform fmt и загрузка провайдера 0.225.0: выполнены.
- Полный Terraform validate переносится на GitHub runner: запуск провайдера в локальной среде ограничен.

Workflow CI дополнительно выполняет те же backend-тесты с PostgreSQL, validate обеих Terraform-конфигураций
и проверку `docker compose config`. Фактический результат нужно смотреть на последнем коммите PR.

## До сдачи требуется выполнить

- [ ] Подготовить каталог YC с учебным промокодом и доступ сервисного аккаунта.
- [ ] Создать закрытый бакет, проверить versioning.
- [ ] Успешно выполнить Terraform plan/apply из Actions.
- [ ] Убедиться, что `kittygram/production.tfstate` находится в S3.
- [ ] Проверить Security Group: вход22/9000, весь исходящий трафик.
- [ ] Проверить cloud-init и версии Docker/Compose на созданной ВМ.
- [ ] Проверить SSH host key и настроить все Secrets/Variables.
- [ ] Убедиться, что tests.yml содержит актуальный URL созданной ВМ.
- [ ] Выполнить deploy с зелёными итоговыми тестами и Telegram-уведомлением.
- [ ] Зарегистрировать два тестовых аккаунта и проверить вход/выход.
- [ ] Первым аккаунтом создать кота без фото, затем с фото и достижениями.
- [ ] Проверить изменение и удаление своей карточки.
- [ ] Вторым аккаунтом проверить чтение и невозможность изменения чужой карточки.
- [ ] Проверить пагинацию при количестве котов больше десяти.
- [ ] Повторить deployment и убедиться, что данные/фото сохранились.
- [ ] Сохранить URL успешных Actions runs, JUnit artifact и скриншоты сайта/облака.
- [ ] Отправить публичный репозиторий на ревью.

Эти пункты не отмечены заранее: локальные тесты не доказывают успешное облачное развёртывание.
